Class Overview

Controller managing the voice user interface (VUI) form attached to a graphical user interface (GUI) activity.

This controller manages the VUI aspects of a GUI activity and speech-enables controls that are supported by the web service for speech recognition. The VUI controller will initialize with the contents of the GUI activity as soon as it is created. The application is responsible for keeping the VUI in sync with subsequent changes to the GUI view hierarchy by calling synchronize().

The VuiController instance can be created either declaratively, in the layout XML file of the activity, or programmatically. In both cases, all speech-enabled views should be children of the VuiController instance. It is therefore practical to instantiate the VuiController class as the root view of the activity's view hierarchy.

public void synchronize ()

Forces synchronization of the VUI form and the activity contents.

This method synchronizes the VUI form, controlled by this VUI controller, with the GUI of the view object referenced. You must call this method to trigger synchronization when the GUI layout of the GUI view contents are changed by your application (e.g. you add or remove controls).

Synchronizing should be done once you have updated all of your GUI view contents, so the VUI form can be updated in one step. Additionally, do not synchronize GUI views that are currently not visible to the user, unless you want to pre-cache a GUI view that will be shown in the immediate future.
